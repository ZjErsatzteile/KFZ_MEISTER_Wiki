# KFZ MEISTER Wiki – V3

Diese Version baut das Wiki zu einer echten Werkstatt-Wissensdatenbank aus.

## Was neu ist

- breiter Hersteller-/Modellkatalog
- Fahrzeug → Baureihe → Motor/Getriebe/Antrieb
- fahrzeugbezogene Reparaturzuordnung
- ausführliche Schritt-für-Schritt-Anleitungen
- mehrere originale schematische Lehrgrafiken pro Arbeitsschritt
- Werkzeug- und Ersatzteillisten
- Vorprüfung und Nachkontrolle
- Diagnosefälle
- technische Werte bewusst als fahrzeugspezifisch zu verifizieren markiert
- Suche über Hersteller, Fahrzeuge, Reparaturen und Diagnose

## Bilder

Die SVGs in `images/repairs/` und `images/diagrams/` sind selbst erstellte schematische Lehrgrafiken. Sie sind keine Herstellerfotos.

Für eine echte Foto-Werkstattanleitung können später pro Fahrzeug und Schritt eigene Fotos ergänzt werden.

## Wichtig

Das Paket behauptet nicht, dass eine allgemeine Anleitung auf jeden Motor oder jede Ausstattung identisch passt. Sicherheitskritische Drehmomente, Füllmengen, Verschleißgrenzen, Anzugswinkel und Diagnose-/Anlernverfahren müssen anhand der exakten Fahrzeugkonfiguration geprüft werden.

## Installation

Bestehende Dateien sichern und anschließend die neuen Dateien in das GitHub-Pages-Repository übernehmen. `database.json`, `app.js`, `style.css` und `index.html` müssen zusammenpassen.
