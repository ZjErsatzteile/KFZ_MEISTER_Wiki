# Inhalte erweitern

## Diagnose
Jeder Eintrag enthält:
- `name`
- `symptom`
- `cause`
- `checks`
- `repair`
- `severity`

## Komponenten
Jede Komponente enthält:
- `system`
- `tools`
- `parts`
- `torque`
- `steps`
- `after`

## Sichere technische Daten
Für ein konkretes Fahrzeug sollten folgende Felder ergänzt werden:
- VIN/FIN
- Baujahr
- Motorcode
- Getriebecode
- PR-/SA-Codes bzw. Ausstattung
- Herstellerquelle / Dokument-ID
- Drehmoment
- Anzugswinkel
- Mindestmaß / Verschleißgrenze
- Füllmenge
- Betriebsstoff-Freigabe
- Lern-/Grundeinstellverfahren

Niemals einen generischen Wert als fahrzeugspezifischen Wert ausgeben.
